# 🎯 나만의 퀴즈 게임

터미널에서 동작하는 Python 콘솔 퀴즈 게임입니다. (Mission 2 과제)

## 프로젝트 개요

Python 기본 문법과 클래스(객체 지향)를 사용해 만든 4지선다 퀴즈 게임입니다.
메뉴에서 기능을 선택해 퀴즈를 풀고, 새 퀴즈를 등록하고, 최고 점수를 확인할 수 있습니다.
퀴즈와 점수는 `state.json` 파일에 저장되어 프로그램을 종료해도 유지됩니다.
Git으로 기능 단위 커밋과 브랜치 병합을 실습하며 개발했습니다.

## 퀴즈 주제와 선정 이유

주제는 **영화**입니다. 한국 영화와 해외 영화 모두에서 문제를 만들 수 있어 소재가 풍부하고,
누구나 부담 없이 풀 수 있는 상식 수준의 문제를 내기 좋아서 선택했습니다.

## 실행 방법

```bash
python main.py
```

- Python 3.10 이상이 필요합니다.
- 외부 라이브러리 없이 표준 라이브러리만 사용합니다.

## 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 등록된 퀴즈를 랜덤 순서로 출제하고 정답/오답과 최종 점수를 표시 |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력받아 새 퀴즈 등록 및 저장 |
| 3 | 퀴즈 목록 | 등록된 퀴즈 전체를 번호와 함께 출력 |
| 4 | 점수 확인 | 최고 점수 확인 (아직 풀지 않았으면 안내) |
| 5 | 종료 | 데이터 저장 후 종료 |

추가로 다음 예외 상황을 처리합니다.

- 숫자 입력 검증: 공백 제거, 빈 입력, 숫자가 아닌 값, 범위 밖 숫자 → 안내 후 재입력
- `Ctrl+C`(KeyboardInterrupt), 입력 스트림 종료(EOF) → 데이터 저장 후 안전 종료
- 데이터 파일이 없으면 기본 퀴즈 5개로 시작, 손상되었으면 안내 후 기본 데이터로 복구

## 데이터 파일 설명 (`state.json`)

- **경로**: 프로젝트 루트의 `state.json` (UTF-8 인코딩)
- **역할**: 퀴즈 목록과 최고 점수를 저장해 프로그램을 다시 실행해도 데이터가 유지되도록 함
- **생성 시점**: 퀴즈 추가/풀기/종료 시 자동 저장. 파일이 없으면 기본 퀴즈로 시작
- **스키마**:

```json
{
  "quizzes": [
    {
      "question": "영화 '인터스텔라'의 감독은?",
      "choices": ["크리스토퍼 놀란", "스티븐 스필버그", "제임스 캐머런", "리들리 스콧"],
      "answer": 1
    }
  ],
  "best_score": 80
}
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `quizzes` | 배열 | 퀴즈 목록 |
| `quizzes[].question` | 문자열 | 문제 |
| `quizzes[].choices` | 문자열 배열(4개) | 선택지 |
| `quizzes[].answer` | 정수(1~4) | 정답 번호 |
| `best_score` | 정수 또는 null | 최고 점수(100점 만점). 아직 풀지 않았으면 null |
